Min portfolio

Om sidan 

Det här är min portfolio 

På sidan kan man läsa om mig, mina kunskaper och mina projekt

Jag har fyra HTML-sidor:

index.html - Hem
about.html - Om mig
skills.html - Kunskaper
projeckts.html - Projekt
contacts.html - Kontakt 

Jag använer style.css för att designen på alla sidor.

Responsiv design 

Jag har gjort sidan mobile-first. Det betyder att sidan först är anpassad för små skärmar.

Jag använder 1 breakpoint:

600px - Navigationen och projektkorten kan ligga brevid varandra och kompetenserna visas i tre kolumner 

Jag har testat sidan genom att ändra storleken på webbläsaren.

Flexbox 

Jag använder flexbox till navigationen och projektkort.

På skärmar ligger navigationen under varandra. på större skärmar ligger de bredvid varandra.

Grid

Jag använder grid för mina kompetenser och på om mig 

På små skärmar visas de i en kolumn. på större skärmar visas de i två eller tre kolumner.

Två problem jag löste 

Problem 1 - Navigation
Problem: Navigationen blev trång på små skärmar.
Lösning: Jag använde Flexbox och media query vid 600px
Test: Jag ändrade storleken på webbläsaren och kontrollerade navigationen.

Problem 2 - Bilder 
Problem: Bilderna kunde bli för stora
Lösning: Jag använde max-width 100% 
Test: Jag ändrade storleken på webbläsaren och kontrollerade bilderna
